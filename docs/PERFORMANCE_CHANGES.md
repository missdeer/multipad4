# 性能优化实施记录

2026-11-14，针对 [静态审查](PERFORMANCE_REVIEW.md) 的 12 项发现完成实现。第三方原始源码未修改。

| 审查项 | 实现 |
|---|---|
| 1：状态栏重复扫描 | 新增 StatusStatistics，按文档 revision、光标、选择和 tab width 缓存；以 16 KiB 块、约 2 ms 时间预算增量计算。FastView 和隐藏状态栏跳过普通全文统计，相同显示内容跳过重绘。 |
| 2：全局刷新及平方级查找 | 合并待处理文档消息，选择/滚动走轻量刷新；HWND 和 buffer id 使用哈希索引。仅文档列表、标题或活动标签实际变化时通知插件；OpenDocuments 对仅激活变化只更新选择。工具栏仅提交变化状态，弹出菜单时刷新菜单状态。 |
| 3：输入内同步全文补全 | 自动补全限制在光标附近 128 KiB，文档扫描预算最多 4 ms；显式补全命令保留配置的扫描预算和全文范围。超长自动补全前缀跳过；扫描采用高精度时钟，长空白扫描也检查剩余预算。 |
| 4：目录搜索内存峰值 | 解码后的大于 1 MiB 文件写入自动清理的 UTF-8 临时快照；密集命中使用固定记录归档，最多 4096 条缓冲后落盘。小结果无需创建命中临时文件。结果队列维持原有最多 8 个结果，每个结果的全文和命中缓冲受上述阈值约束。 |
| 5：局部命令全文复制 | 高级编辑范围 helper、格式化、表达式、选区命令、字符信息、空白转换、行注释、RTF 选区及结果导航改用 Range 或必要的相邻字符查询。需要搜索任意周围块注释等全文语义的操作保留全文访问。 |
| 6：自动保存阻塞 | 定时自动保存逐次捕获 256 KiB，验证 revision、编码、EOL 和路径；后台完成写盘，UI 线程接收结果。全窗口最多一个在途快照；前台保存/重载/关闭先处理对应在途任务。挂起/关机强制保存及显式同步入口保留同步语义。 |
| 7：搜索展示独占 UI | 每次定时器处理一个文件结果，结果页最多 64 条命中，预览最多约 2 KiB。打开的普通文档分片捕获快照后在工作线程搜索；映射文档使用已有异步枚举。结果窗关闭撤销记录，结果导航检查文档 revision 或磁盘文件版本。 |
| 8：换行平方级搬移 | 用偏移量遍历 UTF-16 字符串，不反复 erase 头部；成段跳过空格，保留代理项边界。 |
| 9：排序重复构造键 | 每行预计算完整键、可选列键和扩展名键；稳定排序索引，比较结束后移动行内容。只在需要 remove/unique/merge 时建立对应数据。 |
| 10：重载重复读盘 | 编码检测及兼容回退复用同一份读取字节。 |
| 11：高亮预算累加 | 全窗口约 4 ms 调度预算，活动文档优先，其余轮转；通知中仅准备高亮状态。高频工作定时器仅在有任务时运行。 |
| 12：分页全量着色 | 新增行立即局部着色；分页及样式通知只处理脏范围，完成搜索仅修改相应搜索头。 |

另接入 Scintilla direct function：仅在所属 UI 线程使用，其他线程仍走窗口消息；保留 GETCOLUMN 的项目适配。增加 `MULTIPAD4_ENABLE_IPO` 和 `msvc-release` preset，提供可选 Release LTO 配置；普通开发构建仍使用原配置。没有改变最低 ISA 要求。

## 验证

- 通过仓库 MSVC wrapper 重新配置及编译。
- 完整 CTest：12/12 通过，覆盖编辑器、无插件编辑器、大文件、文件 I/O、搜索、惰性文档、SIMD、单实例、第三方插件、插件管理和内置窗格重启。
- 最后调整命中归档为按需创建后，重新执行受影响的文件搜索、大文件及两种编辑器集成测试。
- 新增回归验证长行/Unicode/tab/multiple-selection 统计一致性、捕获中编辑作废快照、异步备份内容及 revision、前台保存取消在途备份、大文件/密集命中归档和原文件替换后的快照稳定性。
- `git diff --check` 通过。
- 使用 `--qa-render` 导出应用自身窗口，检查搜索结果的命中样式、折叠和状态栏布局；截图保存在 `tmp/performance-qa/Search-results.png`。

本机 RelWithDebInfo、SSE4.2 开发构建的一次测量中，8 MiB 长行的最长统计分片约 2.03 ms；同样大小文档的四字节范围读取 1000 次约 0.24 ms，旧全文复制后截取方式 20 次约 48.5 ms。这是独立操作的微基准，不是整个编辑器的提速倍数。direct function 的短查询结果随运行波动，没有据此宣称稳定加速。每次 smoke test 在其工作目录写入 `performance-checks.txt`。

Release LTO 配置尚未进行对照性能测量；PGO 未启用，需要先确定有代表性的训练负载。没有将这些配置作为 12 项优化的实测收益。

## 可见行为

长行或大选区统计未完成时，状态栏相应字段暂时显示 `...`。自动文档词补全优先附近文本，显式补全仍可扫描全文。自动 occurrence 高亮跳过超过 256 字节的选择，显式搜索/标记命令仍可处理更长文本。搜索结果按 64 条命中分页，超长命中行显示有限上下文；完整位置保留用于导航。
